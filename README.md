# TP – Le Langage SQL

Ce dépôt contient le compte rendu complet du TP consacré au langage SQL avec Oracle.

Le fichier PDF présente les différentes parties du TP :
- Création des tables.
- Mise à jour de la base de données.
- Interrogation de la base de données à travers des requêtes SQL.

**Technologie utilisée :** Oracle SQL*Plus.
